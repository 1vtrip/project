Учебный проект: Telegram-бот для автоматической ежедневной рассылки расписания занятий студентам БГУИР.

## 📝 Описание проекта

Этот бот предназначен для использования в студенческих беседах (чатах групп). После добавления бота в беседу администратор беседы привязывает её к номеру своей учебной группы командой `/setgroup`. Бот сохраняет эти данные и с понедельника по субботу утром (по умолчанию в 7:00 по Минску) автоматически отправляет актуальное расписание на текущий день с учетом текущей учебной недели (1-4). Если пар в этот день нет, бот ничего не присылает.

### Ключевые особенности:
- **Гибридная архитектура:** Проект написан на стыке двух языков. Тяжелая логика обработки данных реализована на высокопроизводительном **C++**, а асинхронное взаимодействие с Telegram и базой данных — на **Python**.
- **Легковесность и надежность:** Локальная СУБД SQLite в связке с асинхронным драйвером `aiosqlite` работает быстро и не блокирует бота, отдельный сервер БД не нужен.
- **Полная автоматизация:** Встроенный планировщик задач сам следит за временем и запускает рассылку. Если бота удалили из беседы, подписка снимается автоматически.

### Команды бота

| Команда | Что делает | Кто может |
|---|---|---|
| `/start`, `/help` | справка | все |
| `/setgroup 521704` | привязать беседу к группе (номер из 6 цифр, бот проверяет, что группа существует) | администраторы беседы |
| `/today` | расписание на сегодня с кнопками «Сегодня / Завтра / 7 дней» | все |
| `/stop` | отключить рассылку | администраторы беседы |

В личных сообщениях с ботом ограничений нет.

## 🏗 Архитектура

Проект разделен на два независимых слоя:
1. **Data Engine (C++):** Выполняет сетевые запросы к официальному API БГУИР (`https://iis.bsuir.by/api/v1/schedule`), парсит JSON-ответ, высчитывает текущую неделю, фильтрует предметы на нужный день и возвращает готовый к отправке результат.
2. **Bot & DB Layer (Python):** Отвечает за интерфейс (команды и кнопки Telegram), асинхронную работу с базой данных SQLite (сохранение `chat_id` и номеров групп) и планирование утренних рассылок с помощью `APScheduler`.

Бот зависит только от интерфейсов из `bot_skeleton/bot/interfaces.py` (`ChatRepository`, `ScheduleProvider`). Пока база данных и C++-модуль не подключены, бот работает на заглушках; потом заглушки заменяются настоящими классами, а код бота не меняется.

## 👨‍💻 Распределение ролей в команде

Проект разрабатывается командой из 3 человек. Зоны ответственности распределены следующим образом:

### 1. Telegram-бот и Планировщик (Студент 1)
**Стек:** Python, `aiogram 3.x`, `asyncio`, `APScheduler`
* Разработка логики Telegram-бота (роутеры, хендлеры, кнопки).
* Обработка команд `/start`, `/help`, `/setgroup <номер>`, `/today` и `/stop`.
* Реализация логики добавления бота в беседу и проверки прав администратора.
* Настройка планировщика `APScheduler` для запуска рассылки с понедельника по субботу в заданное время.

### 2. Core Data Engine (Студент 2)
**Стек:** C++ (C++17), `CMake`, `nlohmann/json`
* Настройка системы сборки CMake для C++ проекта.
* Выполнение HTTP/HTTPS GET-запросов к API расписания БГУИР.
* Десериализация и парсинг JSON-ответов.
* Реализация алгоритма вычисления текущей учебной недели и фильтрации массива занятий по дню.
* Форматирование отфильтрованных данных для передачи в Python-слой (через stdout).

### 3. База Данных и Интеграция (Студент 3)
**Стек:** Python, SQLite, `aiosqlite`, `subprocess`
* **Работа с БД:** Таблица для хранения связок `[chat_id : group_number]` и SQL-запросы (`CREATE TABLE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE`) через `aiosqlite` для неблокирующей работы из асинхронного бота.
* **Связка языков (IPC):** Вызов скомпилированного C++ бинарника через стандартный модуль `subprocess`, передача ему номера группы и даты, чтение результата из `stdout` и обработка кодов выхода.
* **Оформление сообщений Telegram:** Преобразование сырого текста от C++ модуля в удобное для чтения сообщение с разметкой `HTML` и эмодзи.

## 🚀 Запуск проекта (для разработчиков)

*(Раздел будет дополняться по мере разработки)*

### Требования:
* Python 3.10+
* Компилятор C++ с поддержкой C++17
* CMake 3.15+

### Шаги установки:
1. Клонировать репозиторий: `git clone https://github.com/1vtrip/project.git`
2. Собрать C++ модуль:
   ```bash
   cd cpp_core
   cmake -B build
   cmake --build build
   ```
3. Установить Python зависимости:
   ```bash
   cd bot_skeleton
   pip install -r requirements.txt
   ```
   На Windows дополнительно: `pip install tzdata` — без него не работают часовые пояса.
4. Скопировать `bot_skeleton/.env.example` в `bot_skeleton/.env` и вписать токен бота от @BotFather в `BOT_TOKEN`. Там же можно поменять часовой пояс (`BOT_TZ`) и время рассылки (`SEND_HOUR`, `SEND_MINUTE`). Файл `.env` в git не попадает.
5. Запустить бота из папки `bot_skeleton`: `python -m bot.main`
