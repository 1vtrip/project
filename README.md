Учебный проект: Telegram-бот для автоматической ежедневной рассылки расписания занятий студентам БГУИР. 

## 📝 Описание проекта

Этот бот предназначен для использования в студенческих беседах (чатах групп). После добавления бота в беседу, администратор или студент устанавливает номер своей учебной группы. Бот сохраняет эти данные и каждое утро (например, в 7:00) автоматически отправляет актуальное расписание на текущий день с учетом текущей учебной недели (1-4).

### Ключевые особенности:
- **Гибридная архитектура:** Проект написан на стыке двух языков. Тяжелая логика обработки данных реализована на высокопроизводительном **C++** (составляет более 30% кодовой базы), а асинхронное взаимодействие с Telegram и базой данных — на **Python**.
- **Надежность:** Использование СУБД PostgreSQL позволяет боту легко масштабироваться и обслуживать сотни бесед без блокировок.
- **Полная автоматизация:** Встроенный планировщик задач сам следит за временем и триггерит рассылку.

## 🏗 Архитектура

Проект разделен на два независимых слоя:
1. **Data Engine (C++):** Выполняет сетевые запросы к официальному API БГУИР (`https://iis.bsuir.by/api/v1/schedule`), парсит сложный JSON-ответ, высчитывает текущую неделю, фильтрует предметы строго на "сегодня" и возвращает чистый, готовый к отправке результат.
2. **Bot & DB Layer (Python):** Отвечает за интерфейс (команды Telegram), асинхронную работу с PostgreSQL (сохранение `chat_id` и номеров групп) и планирование утренних рассылок с помощью `APScheduler`.

## 👨‍💻 Распределение ролей в команде

Проект разрабатывается командой из 3 человек. Зоны ответственности распределены следующим образом:

### 1. Telegram-бот и Планировщик (Студент 1)
**Стек:** Python, `aiogram 3.x`, `asyncio`, `APScheduler`
* Разработка логики Telegram-бота (роутеры, хендлеры).
* Обработка команд `/start`, `/help` и `/setgroup <номер>`.
* Реализация логики добавления бота в беседу и проверки прав.
* Настройка планировщика `APScheduler` для ежедневного запуска функции рассылки в заданное время.

### 2. Core Data Engine (Студент 2)
**Стек:** C++ (C++17/20), `CMake`, `cpr` (C++ Requests), `nlohmann/json`
* Настройка системы сборки CMake для C++ проекта.
* Выполнение HTTP/HTTPS GET-запросов к API расписания БГУИР.
* Десериализация и парсинг JSON-ответов.
* Реализация алгоритма вычисления текущей учебной недели и фильтрации массива занятий по текущему дню недели.
* Форматирование отфильтрованных данных для передачи в Python-слой (через stdout).

### 3. База Данных и Интеграция (Студент 3)
**Стек:** Python, PostgreSQL, `asyncpg`, `subprocess`, `Docker`
* Проектирование схемы БД PostgreSQL для хранения связок `[chat_id : group_number]`.
* Написание асинхронных CRUD-запросов (создание пула соединений, добавление, обновление и чтение групп).
* Реализация межпроцессного взаимодействия (IPC) — вызов скомпилированного C++ бинарника из Python через модуль `subprocess`, передача ему аргументов и чтение результата.
* Декорирование итогового сообщения: преобразование сырого текста от C++ модуля в красивое сообщение для Telegram с использованием `HTML` или `MarkdownV2` и эмодзи.

## 🚀 Запуск проекта (для разработчиков)

*(Раздел будет дополняться по мере разработки)*

### Требования:
* Python 3.10+
* Компилятор C++ (GCC/Clang/MSVC) с поддержкой C++17
* CMake 3.15+
* PostgreSQL (или Docker для запуска контейнера с БД)

### Шаги установки:
1. Клонировать репозиторий: `git clone <url>`
2. Собрать C++ модуль:
   ```bash
   cd cpp_core
   mkdir build && cd build
   cmake ..
   cmake --build .
   ```
3. Установить Python зависимости: `pip install -r requirements.txt`
4. Настроить переменные окружения (создать файл `.env` с токеном бота и URL базы данных).
5. Запустить бота: `python main.py`
